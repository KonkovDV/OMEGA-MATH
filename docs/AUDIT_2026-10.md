# Аудит OMEGA, октябрь 2026

Дата: 13.10.2026. Начальная точка аудита — `main` на коммите `b24935d`. Все исправления уже в `main`, список ниже.
Локальная проверка шла на Windows 11, Python 3.12.10. CI работает на Ubuntu с Python 3.12 и 3.13.

## Коротко

OMEGA не пытается доказывать теоремы сама. Это рабочая среда для исследования открытых математических задач с помощью ИИ: реестр задач в YAML со схемой, триаж по тому, насколько задача поддаётся ИИ, пошаговый процесс по каждой задаче, журналы экспериментов, пакеты доказательств, адаптеры к Lean, SAT/SMT и CAS. Демонстрационных направлений три: гипотеза Эрдёша — Штрауса, треугольники Кобона и задача Томсона.

Главный вывод: инфраструктура аккуратная, а в границах заявленного честная. Новых математических результатов в репозитории нет, и сам репозиторий их не заявляет. На момент начала аудита самыми слабыми местами были устаревшие цифры в README, численно ненадёжная сертификация задачи Томсона и тесты, которые не проходили на Windows. Всё это исправлено.

## 2. Red Team

Что пробовал сломать:

- **Сертификацию Томсона.** Нашёл две дыры, T2 и T3. Атака простая: подать седловую конфигурацию с одной отрицательной модой. До исправления она могла пройти как «numerical-local-minimum-candidate».
- **Перебор в Эрдёше — Штраусе.** `find_decomposition` ищет x только до n и y до `max_denom`. Если решение не найдено, это не контрпример: скрипт честно пишет `failures`, а не «гипотеза опровергнута». Список остатков `1, 121, 169, 289, 361, 529 (mod 840)` совпадает с результатом Морделла, его приводят и Салез, и arXiv:2509.00128.
- **Воспроизводимость между ОС.** Тесты, зелёные на Linux, падали на Windows (T4). Значит, заявленная воспроизводимость держалась на кодировке среды.
- **Самоподтверждение.** Последние коммиты (`c765c97`, `b24935d`) запрещают оркестратору повышать класс доказательства без названного проверяющего. Обойти это через CLI я не смог.
- **Подмена данных Einstein Arena.** Еженедельный импорт берёт README чужого репозитория без проверки подписи или хеша. Худший случай: бот откроет PR с подменёнными числами. Сливать такой PR вслепую нельзя.

## 3. Murder Board

Вопросы недружелюбной комиссии и честные ответы.

1. **«Что здесь нового по сравнению с AlphaProof, Aletheia и агентом DeepMind для Erdős problems?»** По математике ничего. Новизна в другом: реестр, триаж и дисциплина доказательств для небольшой лаборатории. Это инструмент учёта, а не решатель.
2. **«Есть ли хоть один результат, которого не было до OMEGA?»** Нет. Направления Эрдёша — Штрауса и Томсона воспроизводят известные значения на малых n. Гипотеза проверена до 10^17 (Салез, 2014) и до 10^18 (arXiv:2509.00128), а скрипт OMEGA проверяет сотни простых.
3. **«Триаж по пригодности для ИИ: кто его откалибровал?»** Размечены 73 задачи из 252 (29%), критерии экспертные, сверки с реальными исходами нет. Это слабое место. Есть с чем сверяться: вики Тао по вкладу ИИ в задачи Эрдёша и FrontierMath Erdős.
4. **«Lean заявлен, но работает ли он?»** Отчёт зрелости честно пишет `WARNING`: на проверенной машине нет Lean/Lake и z3. На начало аудита формальных доказательств не было; теперь есть одно, элементарное (случай n ≡ 3 mod 4), и оно проверяется в CI.
5. **«Зачем 50 КБ протокола при восьми коммитах?»** Протокол опережает практику. Пока документации больше, чем результатов.

## 4. Взгляд рецензента
